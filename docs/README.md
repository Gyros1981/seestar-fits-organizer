## 🎨 Screenshot Style Guide

### For Google Docs:

1. **Window Size**: 1280x720 or 1920x1080 for consistency
2. **Clean Desktop**: Hide unrelated icons/notifications
3. **Consistent Theme**: Use dark mode throughout
4. **Clear Annotations**: 
   - Red arrows for buttons to click
   - Yellow highlights for important text
   - Numbered callouts for sequential steps

### Annotation Tools:

**Windows Built-in:**
- Snip & Sketch (Win+Shift+S) - basic arrows/text
- Paint 3D - more annotation options

**Free Alternatives:**
- ShareX (free, powerful annotations)
- Greenshot (free, good arrows/callouts)

**Professional:**
- Snagit (paid, best for documentation)
- Camtasia (paid, screenshots + video)

## 📝 Copy-Paste to Google Docs Instructions

### Method 1: Simple Copy-Paste
1. Open `.md` file in any text editor
2. Select all (Ctrl+A)
3. Copy (Ctrl+C)
4. Paste into Google Doc
5. Format as needed (headings, bullet points)

### Method 2: Markdown to Google Docs
1. Use a Markdown converter (like docs-to-markdown add-on)
2. Or paste and manually format:
   - `# Heading` → Heading 1 style
   - `## Heading` → Heading 2 style
   - `- item` → Bullet list
   - `[text](url)` → Link

### Adding Screenshots:
1. Take screenshot
2. Add arrows/callouts in image editor
3. In Google Docs: Insert → Image → Upload from computer
4. Position below relevant [SCREENSHOT] marker
5. Delete the [SCREENSHOT] placeholder text

## 🎯 Priority Order for Documentation

If creating docs incrementally, prioritize:

1. **Overview** - Users need to understand the app first
2. **Direct Copy** - Most common workflow
3. **FITS Viewer** - Most complex tool, needs clear guidance
4. **Settings** - Reference users will return to
5. **Troubleshooting** - Saves support time
6. **Planetary & Scenery** - Niche but important
7. **Intermediate Copy** - Advanced users
8. **Project Analyzer** - Detailed reference
