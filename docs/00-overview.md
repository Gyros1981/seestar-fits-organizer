# Seestar FITS Organizer - User Guide

## Application Overview

Seestar FITS Organizer helps you manage and organize astrophotography data from your Seestar telescope.

---

## Main Menu Bar

**[SCREENSHOT: Full application window showing menu bar at top with all buttons]**

**[ARROW: Point to 🏠 Home button]** Click to return to the welcome/landing page from anywhere in the app.

**[ARROW: Point to 📥 Import button]** Opens the Import menu with three workflows:
- Direct Copy (Raw → Projects)
- Intermediate Copy (Raw → [process] → Projects)  
- Planetary & Scenery (media files)

**[ARROW: Point to 🔧 Tools button]** Opens the Tools menu:
- FITS Viewer
- Project Analyzer

**[ARROW: Point to ⚙️ Settings button]** Opens application settings.

**[ARROW: Point to ❓ Help button]** Opens Help menu with About and documentation options.

**[ARROW: Point to ❌ Exit button]** Closes the application.
